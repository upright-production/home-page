# 直立製作公司官網

直立製作設計有限公司的繁體中文形象首頁。使用原生 HTML / CSS，無套件或建置依賴，適合 GitHub Pages。

## 本機預覽

直接開啟 `index.html`，或使用任一靜態檔案伺服器預覽本目錄。

## GitHub Pages 上線

將檔案推送至 GitHub 後，在 repository 的 **Settings → Pages** 選擇 **Deploy from a branch**，指定包含網站檔案的分支及 **/(root)**。所有資源均使用相對路徑，可部署於 repository 子路徑。

目前未設定自訂網域。待確認網域及 DNS 後，再於 GitHub Pages 設定。

## 內容維護

- `index.html`：公司介紹、服務與聯絡資訊。
- `styles.css`：桌面與手機版面。
- `assets/upright-logo.png`：使用者提供的原始品牌圖片。
- 聯絡連結使用 `mailto:info@uprightproduction.com`，由訪客的郵件程式開啟。

網站未加入未經提供的客戶案例、認證、地址或年資數字。
